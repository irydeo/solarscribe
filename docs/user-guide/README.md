# SolarScribe user guide

*Guía de usuario. En construcción / Work in progress.*

The guide will walk through a session, step by step: find the Sun, polar
alignment, ROI and scanning, with plain language and one main action per step.

La guía recorrerá una sesión paso a paso: buscar el Sol, alineación polar, ROI y
escaneado, en lenguaje llano y con una acción principal por paso.
