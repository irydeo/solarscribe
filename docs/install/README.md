# Installation / Instalación

*Bilingüe ES/EN. Estado: borrador de diseño (2026-11-06).*
*Bilingual ES/EN. Status: design draft (2026-11-06).*

- **English**: [INSTALL.md](INSTALL.md).
- **Español**: [INSTALACION.md](INSTALACION.md).

SolarScribe is planned for **Windows 10/11 x64** and **Linux** (`.deb` and
`.rpm`), both functional out of the box. The installers will be published on
GitHub Releases; today the only working path is a source install, and the GUI is
still being written. The guide is explicit about which steps are available and
which are planned.

SolarScribe está previsto para **Windows 10/11 x64** y **Linux** (`.deb` y
`.rpm`), ambos funcionales de serie. Los instaladores se publicarán en GitHub
Releases; hoy el único camino que funciona es la instalación desde el código
fuente, y la interfaz todavía se está escribiendo. La guía distingue con claridad
qué pasos están disponibles y cuáles están previstos.

Prerequisites in one line: the ASCOM Platform and the vendor driver on Windows for
the mount; `indiserver` and the mount driver on Linux; USB 3 and a fast disk for
the camera.

Requisitos en una línea: la plataforma ASCOM y el driver del fabricante en Windows
para la montura; `indiserver` y el driver de la montura en Linux; USB 3 y un disco
rápido para la cámara.
