# Installation

*Instalación. En construcción / Work in progress.*

SolarScribe ships for **Windows 10/11 x64** and **Linux** (`.deb` and `.rpm`),
both functional out of the box. The installers are published on GitHub Releases.

- **Windows**: PyInstaller + Inno Setup; the ASCOM Platform (and its .NET
  runtime) is a prerequisite for the mount.
- **Linux**: `.deb` (Debian/Ubuntu) and `.rpm` (Fedora/RHEL); a running
  `indiserver` is a prerequisite for the mount.
