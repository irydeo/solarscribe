# SolarScribe user guide / Guía de usuario

*Bilingüe ES/EN. Estado: borrador de diseño (2026-11-06).*
*Bilingual ES/EN. Status: design draft (2026-11-06).*

- **English**: [USER_GUIDE.md](USER_GUIDE.md).
- **Español**: [GUIA_USUARIO.md](GUIA_USUARIO.md).

The guide walks through a session step by step: find the Sun, polar alignment,
ROI and scanning, with plain language, one main action per step and the limits
written down. It marks every feature as Available, Planned (MVP), Planned (phase
2/3) or Design only, so no planned behaviour is presented as done.

La guía recorre una sesión paso a paso: buscar el Sol, alineación polar, ROI y
escaneado, en lenguaje llano, con una acción principal por paso y los límites
escritos. Marca cada función como Disponible, Previsto (MVP), Previsto (fase 2/3)
o Solo diseño, así que ningún comportamiento previsto se presenta como hecho.

Start with [the documentation index](../README.md) for installation and the
translation workflow.

Empieza por el [índice de documentación](../README.md) para la instalación y el
flujo de traducción.
