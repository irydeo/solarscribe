# SolarScribe user guide / Guía de usuario

*Bilingüe ES/EN. Estado: borrador de diseño (2026-11-07).*
*Bilingual ES/EN. Status: design draft (2026-11-07).*

- **English**: [USER_GUIDE.md](USER_GUIDE.md).
- **Español**: [GUIA_USUARIO.md](GUIA_USUARIO.md).

The guide walks through a session step by step: find Sun, polar, focus, ROI and
scanning, with plain language, one main action per step and the limits written
down. It marks every feature as Available, Wired (simulator), Planned (MVP),
Planned (phase 2/3) or Design only, so no unproven behaviour is presented as done.

La guía recorre una sesión paso a paso: buscar Sol, polar, enfoque, ROI y
barrido, en lenguaje llano, con una acción principal por paso y los límites
escritos. Marca cada función como Disponible, Conectado (simulador), Previsto
(MVP), Previsto (fase 2/3) o Solo diseño, así que ningún comportamiento sin
probar se presenta como hecho.

Empieza por el [índice de documentación](../README.md) para la instalación y el
